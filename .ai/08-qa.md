### Google Drive PDF Upload Live QA — BLOCKED BY CREDENTIAL
- Route tested: `https://wa-gate.buseldata.com/content`.
- Login/session restored successfully in browser.
- Manajemen Konten page renders with DataTable and Upload File CTA.
- Upload dialog renders expected controls: required file chooser, optional name input, category input, `Batal`, `Upload`.
- Direct browser API PDF upload test used a disposable `qa-gdrive-live.pdf` FormData payload.
- Result: `POST /api/content/upload` returned HTTP 500 `{ "error": "Failed to upload file" }`.
- Drive health endpoint result: `GET /api/content/drive/status` returned HTTP 503 with `invalid_grant` because production Worker still lacks `GOOGLE_SERVICE_ACCOUNT_JSON`; it falls back to expired OAuth refresh token.
- Conclusion: UI route/form exists, but actual PDF push to Google Drive cannot pass until Service Account secret is set and target folder is shared with the service account email as Editor.
- UX patch deployed after QA: dialog now labels `File PDF *`, restricts picker to PDF (`accept="application/pdf,.pdf"`), clarifies optional name/category placeholders, disables Upload until a file is selected, and surfaces Drive credential errors in the dialog.
